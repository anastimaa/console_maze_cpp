int y,
int player_id )

Проверяет возможность хода в указанную клетку

Аргументы
[in]xКоордината x
[in]yКоордината y
[in]player_idID игрока (1 или 2)
Возвращает
true, если игрок может сделать ход в указанную клетку, иначе false
Исключения
std::out_of_rangeВ случае, если координаты x или y находятся вне границ лабиринта
std::invalid_argumentВ случае, если указанного игрока (player_id) нет в текущем состоянии игры
