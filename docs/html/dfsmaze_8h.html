Рекурсивная реализация алгоритма DFS для генерации лабиринта. Заимствовано.

Аргументы
[in,out]mazeДвумерный вектор лабиринта (изменяется в процессе генерации)
[in]heightВысота лабиринта
[in]widthШирина лабиринта
[in]start_xНачальная координата X
[in]start_yНачальная координата Y
Исключения
std::out_of_rangeВ случае, если начальные координаты выходят за границы лабиринта
std::invalid_argumentВ случае, если стартовая позиция не является пустой клеткой
Заметки
Функция используется внутренне в dfsmaze_generate()
